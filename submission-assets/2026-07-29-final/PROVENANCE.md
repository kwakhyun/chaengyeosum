# 이미지 제작·내보내기 기록

## 로고

- 라이트 모드 로고는 기존 챙겨썸 3D 준비물 가방 로고를 참조해 밝은 하늘색 불투명 배경으로 변형했어요.
- 다크 모드 로고는 기존 검증된 네이비 배경 브랜드 로고를 사용했어요.
- 두 파일 모두 600×600px PNG이며 투명 채널이 없어요.
- 토스 또는 TDS 제공 아이콘·이미지 리소스를 로고에 사용하지 않았어요.

라이트 로고 최종 프롬프트:

> 기존 챙겨썸 3D 가방의 형태, 체크 배지, 여름 준비물을 유지하고 배경만 밝은 하늘색으로 변경한다. 600×600 앱 로고, 불투명 전체 배경, 텍스트·워터마크·추가 사물·토스 로고 없음.

제작 경로:

- 기본 이미지 편집: Codex built-in ImageGen
- 결정론적 크기·포맷 내보내기: `scripts/build-console-assets-v2.mjs`

## 스크린샷

- 2026-07-29 최신 로컬 앱 `http://localhost:5173/`에서 실제 UI를 촬영했어요.
- 원본 브라우저 뷰포트: 480×791px
- 최종 내보내기: 636×1048px PNG
- 이미지 생성으로 UI를 재구성하지 않고 실제 앱 화면을 사용했어요.
- 홈, 장소와 날씨, 성향 결과, 새 모임 만들기 네 기능을 각각 독립 화면으로 촬영했어요.

## 검증

- `exports/asset-manifest.json`에 각 파일의 크기, 포맷, 알파 채널 여부, SHA-256 해시를 기록했어요.
- 모든 최종 이미지는 불투명 PNG예요.
